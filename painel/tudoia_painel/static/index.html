Governança Canônica Multi-Agente

Fonte única de Regras, Skills procedurais e Servidores MCP propagados para Antigravity, Claude Code (múltiplas instâncias), Cursor e Codex.

Sincronização Canônica Multi-Agente

Ao clicar em Sincronizar Clientes Agora, o sistema lê todas as Regras Canônicas (de governanca/regras/), Skills de Agentes (de skills/) e configurações de Servidores MCP (de config/mcp.json) e as compila e distribui automaticamente para todos os clientes configurados (Google Antigravity CLI, múltiplas instâncias do Claude Code, Cursor IDE e Codex).

Garante conformidade estrita (Zero Drift) entre todas as IAs sem sobrescrever blocos customizados de cada cliente.
