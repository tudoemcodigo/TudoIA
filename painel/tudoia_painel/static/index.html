    Incluir Nova Skill Procedural

    Cole o comando completo do script. A URL e a skill serão extraídas automaticamente.

    Execução Segura: O TudoIA executará o utilitário oficial skills add em sandbox temporário, isolará os arquivos do agente (SKILL.md, referências e templates), importará para a governança canônica e sincronizará instantaneamente com Antigravity, Claude, Cursor e Codex.

    Cadastrar Novo Servidor MCP

    O token será salvo no arquivo .env e protegido no Chaves e segredos.
    Informe uma ou mais variáveis (separadas por vírgula ou espaço). Todas aparecerão automaticamente no Chaves e segredos para mascaramento e teste.

    Adicionar Instância de Cliente

    Identificador interno sem espaços ou caracteres especiais (letras, números, hífens).
    Aceita ~ para a pasta do usuário (ex: ~/.claude-trabalho) ou caminho absoluto.
    Caminho do arquivo JSON onde os servidores MCP são injetados. Se omitido, deduz automaticamente.

    Novo grupo

    Crie um grupo de fallback LiteLLM para receber requisições de agentes ou usuários.

    Prefixo recomendado: tudoia-*. Letras minúsculas e hífens.
    O botão Vincular modelos por papel usará estas opções para filtrar quais modelos entram neste grupo.

    Editar Grupo

    Modifique as informações ou alterne o status operacional do grupo no roteador.

    Ao clicar em Vincular modelos por papel, os modelos compatíveis serão associados a este grupo.
    Status Operacional
    Quando desativado, o LiteLLM não roteará requisições para os membros deste grupo.
